# Dominó Python

Proyecto de aprendizaje de programación en Python.

## Objetivo
Desarrollar un juego de dominó con interfaz gráfica,
aplicando progresivamente fundamentos de programación,
algoritmos y estructuras de datos.

## Tecnologías
- Python 3
- Visual Studio Code
- Tkinter (próximas sesiones)
- Git y GitHub

## Progreso
- [ ] Generar las 28 fichas
- [ ] Mezclar las fichas
- [ ] Repartir a los jugadores
- [ ] Implementar las reglas
- [ ] Construir la interfaz gráfica
- [ ] Implementar un oponente virtual
- [ ] Registrar estadísticas de partidas
